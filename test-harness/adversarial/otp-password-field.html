Two-factor code entered in a password-type box

Reproduces a 2FA "enter the code" step whose single field is type="password".

Correct behavior: NO saved-login dropdown. The field is a one-time verification code (short, numeric, autocomplete="one-time-code"), not a stored password — some sites mask it with type="password", which must not turn it into a login offer.

Verify it's you

A lone type="password" with inputmode="numeric", maxlength="6" and autocomplete="one-time-code". There is no username and no stored-password field on the page.
